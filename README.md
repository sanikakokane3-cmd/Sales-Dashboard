# 📊 Sales Dashboard using Power BI

## 📌 Project Overview
This project presents an interactive Sales Dashboard created using Microsoft Power BI. It helps analyze sales data, track sales performance, identify top-selling products, and understand sales trends through visualizations.

## 🎯 Objectives
- Analyze overall sales performance.
- Track sales and revenue trends.
- Identify top-performing products.
- Visualize important sales insights using charts and graphs.
- Support better business decision-making through data analysis.

## 🛠️ Tools & Technologies
- **Microsoft Power BI** – Dashboard creation and data visualization
- **Microsoft Excel / CSV** – Dataset and data preparation

## 📈 Dashboard Features
- Interactive charts and graphs.
- Sales performance analysis.
- Product-wise sales comparison.
- Sales trend visualization.
- Easy-to-understand visual reports.

## 🔍 Key Learnings
- Data import and transformation.
- Creating visualizations in Power BI.
- Designing an interactive dashboard.
- Analyzing sales data to generate insights.

## 🚀 How to Use
1. Clone or download this repository.
2. Download and install Microsoft Power BI Desktop.
3. Open the `.pbix` dashboard file in Power BI Desktop.
4. Load the dataset if required.
5. Explore the dashboard and interact with the visualizations.

## 📂 Project Files
- `Sales Dashboard.pbix` – Power BI dashboard file (add this file if available).
- `Dataset.csv` – Sales dataset (add this file if included).
- `README.md` – Project documentation.
